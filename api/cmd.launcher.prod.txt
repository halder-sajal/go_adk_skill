package prod // import "google.golang.org/adk/v2/cmd/launcher/prod"

Package prod provides easy way to play with ADK with all available options
without development support (no console, no ADK Web UI) including only
production options like the REST API and A2A support.

FUNCTIONS

func NewLauncher() launcher.Launcher
    NewLauncher returns a launcher capable of serving ADK REST API and A2A.
