package parallelagent // import "google.golang.org/adk/v2/agent/workflowagents/parallelagent"

Package parallelagent provides an agent that runs its sub-agents in parallel.

FUNCTIONS

func New(cfg Config) (agent.Agent, error)
    New creates a ParallelAgent.

    Parallel agent runs its sub-agents in parallel in isolated manner.

    This approach is beneficial for scenarios requiring multiple perspectives
    or attempts on a single task, such as: - Running different algorithms
    simultaneously. - Generating multiple responses for review by a subsequent
    evaluation agent.


TYPES

type Config struct {
	// Basic agent setup.
	AgentConfig agent.Config
}
    Config defines the configuration for a ParallelAgent.
